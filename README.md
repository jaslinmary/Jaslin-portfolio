## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jaslinmary/Jaslin-portfolio.git
```

### 2. Navigate to the project folder

```bash
cd Jaslin-portfolio
```

### 3. Open the project

Open `index.html` in your browser or use the Live Server extension in VS Code.

### 4. Contact Backend

If the FastAPI contact backend is configured, follow the backend project's instructions to install dependencies, configure environment variables and start the API.
